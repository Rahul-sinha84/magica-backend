---
title: "Running tools directly"
description: "Generate, crop or merge media with Magica's models, without a chat."
---

The agent picks tools itself in a conversation. When you already know what you want, run a tool directly:

| Endpoint | Tool | Credits |
| --- | --- | --- |
| [`POST /v1/tools/gpt-image-2`](/api-reference/tools/run-gpt-image-2) | Create an image from a prompt, or edit images | 1,000,000 |
| [`POST /v1/tools/crop-image`](/api-reference/tools/run-crop-image) | Keep a rectangle of an image | 200,000 |
| [`POST /v1/tools/merge-videos`](/api-reference/tools/run-merge-videos) | Join 2 to 100 videos | 500,000 |

The body is the tool's input, checked exactly as the agent's calls are:

```bash
curl -X POST "$MAGICA_API/v1/tools/gpt-image-2" \
  -H "x-api-key: $MAGICA_API_KEY" -H "content-type: application/json" \
  -d '{"mode": "text", "prompt": "A small red paper boat on a calm blue pond, top-down view", "quality": "low"}'
```

```json ToolRunAccepted
{ "runId": "cmuraqzuz00013sitvsxgd7e1", "status": "queued" }
```

Then poll [`GET /v1/tools/runs/{runId}`](/api-reference/tools/get-a-tool-run) (an image usually takes under a minute):

```json ToolRunResponse
{
  "run": {
    "id": "cmuraqzuz00013sitvsxgd7e1",
    "tool": "gpt_image_2",
    "status": "completed",
    "input": { "n": 1, "mode": "text", "size": "1024x1024", "prompt": "A small red paper boat on a calm blue pond, top-down view", "quality": "low", "background": "auto", "output_format": "png" },
    "credits": 1000000,
    "durationMs": 45592,
    "assets": [{ "type": "image", "url": "https://g.tlcdn.com/gen/11e707c5be4f4a20be703f0b715844bf.png", "mimeType": "image/png", "width": 1024, "height": 1024 }],
    "error": null,
    "createdAt": "2026-10-02T18:28:42.635Z",
    "completedAt": "2026-10-02T18:29:31.134Z"
  }
}
```

## How it's charged

The credits are reserved when the run starts and charged **once** if it completes; if it fails (or can't start), they are given back. The result also lands in your Media Library. A run stuck far past its limit is ended when you read it, and its credits returned.

Add a `webhook` next to the input to get `tool.completed` or `tool.failed`. See [Webhooks](/webhooks).
